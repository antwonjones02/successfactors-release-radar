# Release Radar: SAP SuccessFactors 2H 2026

A free, independent guide to the SAP SuccessFactors 2H 2026 release, written for leaders.

**Live site:** https://antwonjones02.github.io/successfactors-release-radar/

- **Exec Brief:** the release on one screen. What breaks if you wait, decisions for leaders, and what employees will notice, each linked to the SAP release notes behind it.
- **Full dashboard:** all 411 changes, sorted by what they ask of you, with a deadline runway, filters, search, and a copy-ready summary for email or Teams.

Built from SAP's public What's New Viewer data (retrieved October 14, 2026). The page is a single self-contained HTML file with no tracking.
